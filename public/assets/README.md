# Imagenes de Perpignan

Para cambiar el visual sin tocar codigo, reemplaza estos archivos manteniendo el nombre:

- `logo.png`: logo del menu principal.
- `app-bg.jpg`: fondo general suave de toda la app.
- `pizza-card-bg.jpg`: imagen alargada y discreta detras del texto de cada pizza.

Si una imagen no existe, la app sigue funcionando y usa el fondo por defecto.
